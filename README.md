## ✨ Features

- **🌌 Interactive Particle Background:** A beautiful interactive particle network built using the HTML5 Canvas API and vanilla JavaScript.
- **💻 Cyberpunk/Dark-Themed UI:** A sleek, modern design using custom CSS variables, glassmorphism (ackdrop-filter), and luminous teal and indigo gradients.
- **🎨 Custom Styled SVGs:** Fully-integrated, animated SVG graphics representing development environments and web elements.

## 🌐 Deploying to Vercel

This repository is optimized for one-click deployment to **Vercel**!

Since the main file is named Muhammad Yahya Alvi.html (instead of the traditional index.html), a custom ercel.json file is included in this repository. It automatically maps the root URL (/) to load Muhammad Yahya Alvi.html seamlessly without changing any of your local file names.

### Steps to Deploy:
1. Push this folder to your GitHub repository.
2. Go to [Vercel](https://vercel.com/) and log in with your GitHub account.
3. Click **Add New** > **Project** and import your portfolio repository.
4. Leave the default settings as they are, and click **Deploy**.
5. Your portfolio is now live on the web! 🎉
